# Beacon 使用说明（局域网版）

## 连接

- 被控端左栏显示本机所有网卡的 IPv4 地址，点复制按钮发给 IT。
- 控制端在输入框填被控端 IP，直接连接，无需输入密码。
- 连接时被控端屏幕右下角会弹出确认窗口（同意 / 拒绝），
  带 10 秒倒计时；无人操作时倒计时结束自动同意，可正常接入无人值守机器。

## 中文输入

- 中文组词由**被控端**的输入法完成：先在被控端把输入法切成中文
  （可以远程按 Shift 切换微软拼音的中英文），然后直接打拼音即可。
- 本机输入法保持英文状态即可；本机切中文不会生效（按键被直接转发）。
- 不要在连接窗口聚焦时按 CapsLock；大写锁定会同步到被控端。
- 键盘模式推荐 Map（1:1），对远端中文组词最可靠。

## 开机自启

- 设置 → 通用 → Other → "开机自启"（Start on boot）。
- 勾选后写入当前用户注册表 Run 项，开机自动运行当前 exe。

## 网络

- 纯局域网：不连接任何公网服务器（无打洞、无中继、无更新检查、
  无云端管理台）。被控端默认只接受内网地址（私有/回环/链路本地）
  的连接，可在 whitelist 选项里进一步限定 IP/网段。
